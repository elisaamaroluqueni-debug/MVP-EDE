# InvestTrack (MVP de simulação)
PHP 8 + MySQL + Bootstrap 5 + Chart.js. Dados fictícios; nenhum dinheiro real.

## Instalação (XAMPP, Windows)
1. Copie a pasta `InvestTrack` para `C:\xampp\htdocs\`.
2. Inicie Apache e MySQL no painel do XAMPP.
3. No phpMyAdmin, importe `database/investtrack.sql` (cria `investtrack_db`, tabelas e dados).
4. Se o utilizador MySQL não for `root` sem palavra-passe, edite `config/database.php`.
5. Abra http://localhost/InvestTrack/

## Admin demonstrativo
`admin@investtrack.ao` / `password` — altere depois do primeiro acesso.
